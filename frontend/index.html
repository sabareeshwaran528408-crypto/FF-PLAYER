ABOUT FF PLAYER

Free Fire Player Database

FF PLAYER is a gaming database project that allows users to search player information using a unique Free Fire UID. Player information is retrieved from the project's MySQL database through a Node.js and Express API.

This project is not affiliated with or endorsed by Garena or Free Fire.
